# DeepSeek Harness 学习资料

> 基于本仓库（`@deepseek-ai/deepseek-harness`，分支 `plugin-1`）源码与官方文档整理的从零学习材料。
> 为你从「完全不懂这个项目」到「能读代码、写插件、参与贡献」设计,所有内容都锚定仓库真实路径。

## 这套资料的定位

这个仓库是 **DeepSeek AI 的 agent harness（智能体框架）**,核心设计哲学是 **「一切皆插件」**,由被 vendor 进来的 **Cordis** 插件框架驱动。它不是传统的单体服务,而是一棵「由配置组装起来的插件树」。

因此,学习这个项目有三个关键认知门槛,本手册会逐步帮你跨过:

1. **Cordis 思维**:服务、上下文、事件、可逆副作用 —— 理解了这套抽象,代码才读得懂。
2. **插件树组装**:一个运行中的 `dsh` 是一层层配置 patch 叠出来的,不是 main() 里硬编码。
3. **核心数据流**:Session 日志 → 模型请求 → 工具调用,这个 Turning 循环是所有行为的骨架。
